# Lincoln War Research Project

The Lincoln War Research Project is treated as a PPW-coordinated supplemental
study for the existing `american-civil-war-union` case and Lincoln evidence
module architecture.

It should not be registered as a separate PPW evidence module unless a later
module-boundary review finds a distinct corpus, annotation layer, or claim
family that cannot be represented under `lincoln-metaphor-analysis` and the
existing Civil War Union case.

Current PPW disposition:

- keep the LWRP Quarto site, generated publication files, and project-specific
  scaffolding in the source repository;
- audit source-register metadata before any source-pack or corpus-extension
  import;
- treat LWRP claim records as draft context only, not PPW findings;
- preserve corpus, thesis, publication, source-rights, and claim-promotion gates.

See
[`docs/migration/lwrp-intake-disposition.md`](../migration/lwrp-intake-disposition.md)
for the intake decision.
